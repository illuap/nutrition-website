# Nutrition Data Explorer

A fast, searchable, and responsive web interface for exploring nutritional data.

## Features
- **Grouped Search**: View unique food items rather than repetitive nutrient rows.
- **Expandable Details**: Click any row to see full nutritional profiles, measurement conversions, and food group details.
- **URL Persistence**: Search queries are saved in the URL, allowing you to refresh or share specific results.
- **Offline-Ready**: Once the CSVs are loaded, filtering and pagination happen instantly in the browser.

## Setup
Simply host the `index.html` and the `data/` directory on any static web server (like GitHub Pages).

## Data Source
This application uses data derived from the Canadian Nutrient File (CNF).
